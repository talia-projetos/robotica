Como funciona

O HUB digital — do juiz ao ranking

Credenciais individuais por juiz

Nome + PIN. Login único para todas as categorias e competições. Cada avaliação carrega a identidade do juiz — rastreabilidade completa.

Rubricas digitais com rascunho offline

Formulário web com critérios 1–4 por área. Rascunho salvo automaticamente no dispositivo — se cair a conexão, os dados não se perdem.

Ranking ao vivo — sem intervenção

A cada envio, o sistema recalcula a ponderação (20% por categoria) e atualiza o ranking. A coordenação não precisa fazer nada manualmente.

Painel de coordenação integrado

Visão consolidada de todas as equipes, status de avaliações, comentários de juízes e deliberação em tempo real com chat interno.

Funciona no celular, sem instalação

PWA instalável. Qualquer juiz com smartphone consegue avaliar — sem depender de computador, sem download de aplicativo.

Recálculo automático a cada 5 minutos

Mesmo que dados sejam ajustados diretamente na planilha, o sistema sincroniza automaticamente. Sem resultado desatualizado.

Perfil individual de cada equipe

Cada turma acessa a própria página com desempenho por categoria, foto e ranking parcial — criando engajamento além do pódio.

Metodologia

O modelo de avaliação

Cada categoria vale 20% do total
Arena · Projeto de Inovação · Design/Engenharia · Core Values · Tampinhas
Rubricas: escala 1 a 4 por critério
10 critérios por rubrica. Média de todos os juízes que avaliaram a equipe naquela categoria.
Arena: melhor round, normalizado
Bruto máx 550 pts → normalizado para 0–100. Apenas o melhor desempenho entre os rounds conta.
Fórmula
TOTAL = Arena×0,20 + Projeto×0,20
         + Design×0,20 + Core×0,20
         + Tampinhas×0,20

Argumento central

O sistema vale menos que quem sabe operá-lo

Um sistema educacional não é um produto com data de entrega. É um processo vivo que precisa ser ajustado quando as regras mudam, quando surgem novas turmas, quando a escola quer ir além. Quem construiu conhece cada decisão que foi tomada — e por quê.

Infraestrutura zero-lock-in

Cada camada usa ferramentas abertas ou já contratadas. Sem vendor lock-in em plataformas pagas de terceiros.

Escala adequada ao volume

Para centenas de envios simultâneos, Apps Script tem margem confortável. Limite relevante começa em dezenas de milhares de chamadas/dia.

Limites técnicos conhecidos
  • Apps Script tem latência variável (1–3s cold start) — perceptível em pico
  • Autenticação baseada em PIN — suficiente para o contexto, limitada para acesso externo
  • Google Sheets como banco de dados tem limite prático de ~10k linhas com boa performance
  • Sem ambiente de staging — testes e produção na mesma planilha
